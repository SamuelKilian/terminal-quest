# Terminal Quest

An interactive terminal adventure game built with Python.

## Features

- Interactive terminal menu
- Mission-based gameplay
- Answer validation and scoring
- Automated tests with pytest

## Technologies

- Python
- Rich
- Questionary
- Pytest

## Run the Game

```bash
python main.py
```

## Run Tests

```bash
python -m pytest -v
```
